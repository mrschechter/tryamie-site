## SEO Best Practices Checklist

For each new article:

### Before Writing
- [ ] Research target keyword (search volume, competition)
- [ ] Identify 3-5 related keywords to include
- [ ] Review top 5 ranking articles for the keyword
- [ ] Plan internal links to existing content
- [ ] Outline with H2/H3 structure

### Writing
- [ ] Target keyword in title, H1, first paragraph
- [ ] 1,500-2,500 words for comprehensive coverage
- [ ] Include FAQ section (helps with featured snippets)
- [ ] Add statistics and cite sources
- [ ] Use bullet points and numbered lists
- [ ] Include relevant product CTAs

### Technical SEO
- [ ] Meta title (50-60 characters with keyword)
- [ ] Meta description (150-160 characters, compelling)
- [ ] Canonical URL set
- [ ] Open Graph tags for social
- [ ] Schema.org Article markup
- [ ] Schema.org FAQPage markup (if FAQ section)
- [ ] Alt text for all images

### After Publishing
- [ ] Add to blog/index.html
- [ ] Update related articles with links to new post
- [ ] Share on social media
- [ ] Submit to Google Search Console
